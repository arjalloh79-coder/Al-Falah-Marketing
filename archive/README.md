# Archive

Legacy Laravel backend and client mockups previously lived in separate GitHub repositories.

- **Production website** lives at the repository root (not under this folder).
- To keep a mockup, copy it into `archive/client-mockups/<project-name>/`.
- Delete obsolete repos on GitHub (Settings → Danger zone → Delete) after confirming nothing unique remains.

GitHub’s API does not allow this automation to delete repositories on your behalf.
