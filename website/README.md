# Production website files

The full production site (HTML pages, assets, admin, API) is maintained for Hostinger `public_html` deploy.

**Canonical repo:** https://github.com/arjalloh79-coder/Al-Falah-Marketing

Because of API size limits, large HTML pages and binary assets may need to be uploaded via:
1. Hostinger File Manager (recommended for full zip), or
2. Local git: clone this repo, copy from your machine, `git push`
